# 3.035 GHz Helical Antenna HFSS Project

Public repository: **[Embedded-AI-Design-Labs-Pvt-Ltd/Helical_Antenna_Design](https://github.com/Embedded-AI-Design-Labs-Pvt-Ltd/Helical_Antenna_Design)**

Double-click **RUN.bat** to open the GUI. Use **DEMONSTRATE** for existing example data, or **TEST IN HFSS** to build the antenna in Ansys Electronics Desktop.

Full project: `helical_antenna_hfss/`

HTML documentation (open after a run, or generate with `python helical_antenna_hfss/scripts/report_generator.py`):

- [Design](helical_antenna_hfss/docs/design.html) — axial-mode helix theory, locked source geometry, targets, assumptions
- [Implementation](helical_antenna_hfss/docs/implementation.html) — GUI procedure, workflow phases, module map
- [Architecture](helical_antenna_hfss/docs/architecture.html) — system block diagram, data flow, control flow
- [Dashboard](helical_antenna_hfss/docs/index.html)

Source document parameters are locked. Feed, materials and air box are documented assumptions. Electromagnetic results are **NOT SIMULATED** until HFSS actually solves. Demonstration numbers are never treated as live Ansys PASS.
