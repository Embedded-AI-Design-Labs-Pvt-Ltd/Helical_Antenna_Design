HFSS project output folder.

- build_helix_hfss.py — IronPython script for Ansys Electronics Desktop
- open_in_ansys.bat — launches AEDT with that script (window stays open)
- Helix_3035MHz.aedt — created when PyAEDT/AEDT successfully builds the model

Use Tools > Run Script if the GUI cannot find ansysedt.exe.
