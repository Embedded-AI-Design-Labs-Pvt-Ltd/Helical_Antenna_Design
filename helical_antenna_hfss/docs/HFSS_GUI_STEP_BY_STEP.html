HFSS GUI — Step by Step

Use this procedure to build the antenna manually in Ansys Electronics Desktop. The RUN button performs the same operations through PyAEDT / Tools > Run Script.

Ground thickness (1.00 mm), feed gap (1.50 mm), copper, 50 Ω lumped port and the air box are ENGINEERING ASSUMPTIONS. Helix R, pitch, turns, wire and ground radius are source values.
